# 方法细节、判定阈值与已知失败模式

## 版面提取

- 工具：`pdftotext -bbox-layout`，逐页导出 page/block/line/word 四级结构及包围盒。
- 文本层判定：单页词数 < 20 视为疑似扫描页（阈值 `WORD_MIN_TEXT_PAGE`，脚本内可改）。
  全文档无文本层且环境有 `pdftoppm` + `tesseract` 时，可 300 dpi 渲染后 OCR；
  否则状态 `unreadable`/`partial`，不编造文字。

## 页眉页脚剔除

- 候选：行中心纵坐标在页面顶部 8.5% 或底部 7.5% 以内。
- 判定：文本 NFKC 归一化、小写化、数字替换为 `#` 后，在 ≥ max(2, 40% 页数) 的页面上出现。
- 剔除项记录于 `removed_running_matter`，可审计、可回溯。

## 分栏与阅读顺序

- 跨栏块：宽度 > 62% 页宽。
- 栏检测：对栏内块按左边缘 x0 聚类（容差 5% 页宽）；取块数最多的两个簇，
  两簇平均 x0 间距 > 15% 页宽且次簇块数 ≥ 首簇 20% 时认定双栏。
  居中块（题名、作者行）不属于任一栏簇，在双栏页上按跨栏块处理。
- 栏归属：块中心落入栏区间（含容差）即归属该栏；栏分割点取两栏区间的中点。
- 横带切分：以跨栏块的上下边界把页面切成横带；横带内先左栏（按纵坐标排序）后右栏。
- 该算法正确处理：标题/作者行跨栏 + 正文双栏、通栏图表打断双栏、单双栏混排、
  栏宽充满版心（左右栏文本几乎相接）的情形。
- 已知限制：三栏且栏宽不均时分割点可能偏移；此时栏内顺序仍正确，栏间可能交错，
  会在 `uncertainties` 中由低置信度标题等信号间接反映。

## 结构识别

- 编号标题：`^(\d+(\.\d+)*)\.?\s+\S` 且块不超过 3 行、不以句号结尾；层级 = 编号段数。
- 无编号标题：Abstract/摘要、Introduction、References/参考文献、Acknowledgements、Appendix 等固定词表。
- 图题：`^(Figure|Fig\.?|图)\s*N`；表题：`^(Table|Tab\.?|表)\s*N`；题注块整体保留。
- 公式：行尾出现 `(N)` 编号且块 ≤ 2 行时登记为编号公式，文本为原文符号串（未转 LaTeX，
  需要 LaTeX 时应以 `bbox` 回查原文核对）。
- 参考文献：进入 References 节后按 `^[n]` 或 `^n.` 切条，跨块续行合并。

## 表格

- 当前版本可靠定位表题与所在区块；网格结构以原文行保留在相邻段落中。
- 需要单元格级还原时，按表题 `bbox` 截取后续同页区块，用 `pdftotext -layout` 的空白列对齐，
  或转人工核对；脚本不臆造单元格归属。

## 失败模式与处置

| 情况 | 行为 |
|-|-|
| 加密/损坏 PDF | `failed`，记录 pdfinfo/pdftotext 原始报错 |
| 全扫描件无 OCR | `unreadable`，不输出猜测文字 |
| 部分页无文本层 | `partial`，页码列入 `uncertainties` |
| 字体乱码（CID 无映射） | 该页词数极低时按扫描页处理；否则原样保留并提示核对 |
| 页码错乱/缺页 | 以物理页序为准，页码锚点始终指物理页 |
