# 方法细节、判定阈值与已知失败模式

## 页面分类与扫描页识别

- 逐页统计词数：0 词 = `empty`（无文字层，扫描/纯图）；1–19 词 = `sparse`（图表页或
  部分提取，**不**判为不可读）；≥ 20 词 = 文本页。
- 仅对 `empty` 页尝试 OCR；`sparse` 页原样保留并写入 `uncertainties`。
- OCR 失败页记录页码与工具报错原文。

## OCR 坐标

- `pdftoppm -r 300 -png -singlefile` 渲染，`tesseract stdout --psm 3 tsv` 取 TSV。
- TSV 第 5 级（word）提供像素坐标 `left/top/width/height`；按 `pt = px × 72/300`
  换算为 PDF 点（页左上角原点），按 (block, par, line) 重组为行与块。
- 禁止按行数/词长估算坐标。OCR 块标记 `source=ocr` 并在 `uncertainties` 注明未经人工核验。
- 坐标换算为纯函数 `parse_tesseract_tsv`，有独立单元检查（不依赖 tesseract 安装）。

## 页眉页脚剔除

- 候选：行中心在顶部 8.5% 或底部 7.5% 以内。
- 判定：NFKC 归一、小写、数字→`#` 后在 ≥ max(2, 40% 页数) 页面出现。
- 单页文档无法靠重复判定，页眉可能残留；元数据提取改用字高规避（见下）。

## 分栏与阅读顺序（1–4 栏）

- 跨栏块：宽度 > 62% 页宽。
- 栏检测：块左边缘 x0 聚类（容差 5% 页宽）；簇按块数排序，仅接受块数 ≥ max(2, 20% 最大簇)
  且与已接受簇平均 x0 间距 > 12% 页宽的簇（最多 4 栏）。
  — 单块"假栏"（如居中表格）被块数下限拒绝；不等宽栏由 x0 聚类天然支持。
- 栏归属：左边缘匹配簇 → 该栏；否则块中心距页心 < 12% 页宽 → 跨栏带块（题名、作者行、
  通栏图表）；再否则按中心落入栏区间归属；都不满足 → 跨栏带块。
- 横带切分：跨栏块上下边界切页为横带；带内各栏从左到右、栏内按纵坐标。
- 支持：通栏标题/图表打断多栏、单双栏混排、栏文本几乎相接（判定用左边缘间距而非右边界）。

## 结构识别

- 编号标题：`^(\d+(\.\d+)*)\.?\s+\S`，剩余部分 ≤ 10 词、不以句末标点结尾、首字符为字母，
  且**每个词都不含数字**（拒绝 `3 results show...` 编号句、`91.2 +1.0` 与 `10 A a2` 表格
  数字行）；层级=编号段数。编号被拆行时仅与**同一视觉行**（y 中心差 < 半行高）、
  大写/中文开头且无数字词的下一行合并。
- 无编号标题：Abstract/摘要/References/参考文献/Keywords 等固定词表。
- 图题 `^(Figure|Fig.|图)N[:.：]`、表题 `^(Table|Tab.|表)N[:.：]` 或 `Table N (continued)`；
  `continued|续表` 标续接。
- 公式：行尾 `(N)` 且含数学符号特征（`=∑∫√≤≥±×÷`、希腊字母、`^`/`_`、LaTeX 片段），
  向前回溯合并不超过 8 词、无句末标点、含数学特征的连续行（多行公式）；
  以括号数字结尾的正文（如"见综述 (3)"）不满足数学特征，不会误判。
- 参考文献：References 节后按 `^[n]`/`^n.` 逐行切条，跨行合并。

## 表格网格（含跨页处理）

1. 题注命中后进入捕获：后续行非标题/题注/散文（≥8 词且几乎无数字）即收为表格体，
   上限 80 行。
2. **页边界处理**：捕获跨页时在页末关闭当前网格（记 `note_page_break`，行不跨页合并）；
   下一页若以 `Table N (continued)` 类题注开头，建立新条目并写 `continuation_of` 关联；
   无重复题注但紧接着是类表格行时，按页断位置推断续接并标 `uncertain: true`。
3. 视觉行合并：被提取器拆开的同一视觉行按 y 中心重叠（容差 0.5×中位行高）合并。
4. 单元格切分：行内词按水平间隙（> max(10pt, 2×中位字宽)）切格。
5. 列对齐：所有格左边缘聚类（容差 12pt）得列边界；格按边界归列，跨列标记 `colspan`
   （合并单元格，记入 `merged_cells`）。
6. 表头：首个数值占比 ≥ 50% 的行为数据起始，其前为（可多行）表头。
7. 列数 < 2 或归属冲突时 `uncertain: true` 并保留原始行——不猜测单元格归属。

## 段落 bbox

- 段落记录组成它的全部文本行；bbox 为这些行的并集，另给 `page_bboxes`（分页 bbox）
  与 `cross_page` 标记。
- 跨块/跨页续接：块末 pending 文本不以句末标点结尾时不清空，延续到下一块/下一页。

## 元数据

- 题名：首页首个章节前的块中**中位行高最大者**（字高≈字号），置信度 medium。
- 作者/单位：题名之外、字高 ≥ 60% 题名的块；含单位词表（university/大学 等）归单位，
  其余 ≤12 词归作者；置信度 low。
- 摘要：Abstract 节下段落拼接，置信度 high。关键词：`^Keywords[:：]`，置信度 high。
- DOI：`10.\d{4,9}/...` 正则，置信度 high。期刊/年份：页眉页脚中含年份的文本行，置信度 low。
- 未找到的字段一律 `null`。

## 失败模式与处置

| 情况 | 行为 |
|-|-|
| 加密/损坏 PDF | `failed`，记录 pdfinfo/pdftotext 原始报错 |
| 全扫描件无 OCR | `unreadable`，不输出猜测文字 |
| 部分页无文字层 | 有 OCR 按真实坐标恢复并标注；无则 `partial` + 页码清单 |
| 少文本图表页 | 保留并标注 `sparse`，不判 unreadable |
| 字体乱码 | 词数极低按无文字层处理；否则原样保留并提示核对 |
| 表格无法可靠成格 | `uncertain` + 原始行保留 |
